# 页面模板

三种结构覆盖 v1 全部界面。新增页面前先确认它属于哪一种，不要发明第四种。

## OOBE 单步

用于首次运行向导、添加账号、添加实例等“一次性决定”的流程。

```
┌──────────────────────────────────────────────┐
│ AppBar  品牌标 标题            反馈 │ 帮助 │ ✕ │ 44
├──────────────────────────────────────────────┤
│ 步骤名 \ 副名                                  │ 24/600 + 72% 白
│                                              │
│            （水印线稿铺满，10%）                │
│                                              │
│              主图标 72–96                      │
│              控件（下拉 / 单选 / 卡片）          │
│                                              │
├──────────────────────────────────────────────┤
│ 一句话说明                      [返回][继续]    │ 72
└──────────────────────────────────────────────┘
```

规则：

1. 内容区只有一个视觉中心：图标 + 一个控件，或两张并排的选项卡。
2. 选项卡用 16:9 预览图，选中态是白色 2px 外描边 + 单选点变实心，不加阴影。
3. 说明文字在动作带左侧，**不重复**步骤名说过的话。
4. 需要额外确认的步骤（音频、网络、写盘授权）用“拖动圆形到轨道末端”或“按住 1.2s”，
   并在原地显示进度，不弹二次对话框。
5. 完成页不再有“继续”：用箭头指向主界面入口，并把剩余可选操作变成一行链接
   （例：`需要继续安装 Minecraft 核心吗？ 点击此处，安装核心。>`）。

HTML 骨架：

```html
<div class="win">
  <header class="appbar">…</header>
  <main class="step">
    <div class="crumb"><b>账户</b><span>\ 创建用户档案</span></div>
    <div class="center">…</div>
  </main>
  <footer class="actionbar">
    <p>BakaXL 使用符合业界标准的加密方式存储您的信息</p>
    <button class="act back">上一步</button>
    <button class="act go">下一步</button>
  </footer>
</div>
```

## 首页

磁贴式布局：AppBar / 标题带 / 磁贴画布 / 动作带。

```
┌──────────────────────────────────────────────┐
│ AppBar  SEALY LAUNCHER              － ▢ ✕    │ 40
├──────────────────────────────────────────────┤
│ [01]  Fabric 1.21.11                          │ 标题带
├──────────────────────────────────────────────┤
│ ┌──┐┌──┐┌─────┐┌─────────┐┌──────────┐      │
│ │▦ ││↓ ││     ││  公告    ││ 最近世界  │      │
│ ├──┤├──┤│ 实例 ││         ││          │      │
│ │👤││⚙ ││     ││         ││          │      │
│ ├──┴┴──┴─────┤│         ││          │      │
│ │ 安装新版本   ││         ││          │      │
│ └────────────┘└─────────┘└──────────┘      │
├──────────────────────────────────────────────┤
│ (H) 您好！ 用户名            [文档] [启动游戏] │ 84
└──────────────────────────────────────────────┘
```

规则：

1. 标题带只放一个 42px 大标题——**就是当前实例名**；不写版本、Loader、上次游玩时间。
2. 磁贴尺寸固定四档：小 84、中 178×178、宽 366×178、大 272×366；不做任意尺寸。
3. 磁贴内容：小磁贴只有图标；中磁贴图标 + 名称；宽磁贴图标 + 名称 + 箭头；大磁贴承载列表或公告。
4. 一屏最多一个 `block` 反色大磁贴（公告），其余全用 `surface` + 发丝线。
5. 最近世界只显示名称与相对时间，版本号收进实例详情页。
6. 动作带左侧是问候与身份，右侧是唯一的 `accent` 主按钮（启动游戏）。
7. 网络、Java、下载源这类运行时信息**不进首页**：放设置页或日志页。

## 列表页

用于实例、下载、日志。

```
AppBar
搜索框 + 分段筛选（全部/正式/快照）
──────────────────────────────
行：名称 | 版本 | 大小 | 状态 | [安装]
──────────────────────────────
ActionBar：左侧进度/统计，右侧主操作
```

规则：

1. 行高 48，列对齐到固定轨道；时间与数值右对齐。
2. 悬停只变底色，不出现新控件；行内操作常驻。
3. 选中态用左侧 2px 绿条 + 6% 绿底，不用整行描边。
4. 虚拟列表滚动条贴右边缘，不出现在内容内边距里。

## 账户流

三段，共用 OOBE 外壳：

1. **选择方式**：三张等宽卡（Microsoft / authlib-injector / 离线），各配一句差异说明。
2. **凭据**：Microsoft 走浏览器 + 设备码兜底（码用 32/600 等宽显示）；
   authlib 填地址与用户名密码；离线只填名称。
3. **角色**：列出该账号可用角色（皮肤头像 64 + 名称 + 类型标签），选中即完成。

规则：账号卡正面显示皮肤头像、名称、验证模式（`离线验证模式`/`微软账户正版`），
模式用 11px 标签而不是颜色区分。
