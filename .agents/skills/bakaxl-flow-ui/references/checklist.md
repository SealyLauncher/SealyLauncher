# 交付自检

逐条勾选。任一条不通过，要么改，要么在交付说明里写出原因——不允许默默跳过。

## 结构

- [ ] 这一屏只有**一个**主操作，且它就是用户此刻要做的决定。
- [ ] AppBar、内容、ActionBar 三区存在且高度固定；动作带没有随内容上下浮动。
- [ ] 没有出现第二个并列主按钮，也没有 hover 才出现的关键操作。
- [ ] 面包屑是唯一标题；没有叠加小标题、副标题、overline。

## 视觉

- [ ] 颜色只承担功能：绿=继续/开始，琥珀=返回，蓝=外壳，红=危险。
- [ ] 没有渐变、玻璃、光晕、多层投影；分层只用色块与 1px 发丝线。
- [ ] 圆角来自 token（窗口 8 / 卡片 6 / 按钮 4），没有随手写 12、16、20。
- [ ] 字号来自阶梯（24/15/13/11），正文不小于 13。
- [ ] 品牌水印不透明度 ≤12%，不遮挡文字与控件。

## 交互

- [ ] 不可逆或授权动作有摩擦（拖动/长按/输入确认词），不是复选框。
- [ ] 主按钮在禁用时有原因提示，不是灰掉不说话。
- [ ] 键盘可达：Tab 顺序 = 视觉顺序，Enter 触发主操作，Esc 关闭浮层。
- [ ] 焦点环 2px 且不被圆角裁掉。

## 文案

- [ ] 一句话说清这一步要什么，不重复标题。
- [ ] 按钮用动词（`开始游戏`、`继续`、`安装`），不用“确定/提交/下一步设置”。
- [ ] 没有“请注意”“成功”“欢迎使用本功能”这类仪式用语。
- [ ] 中文与英文都不溢出：英文按 1.4× 长度预留空间。

## 工程

- [ ] 颜色、圆角、字号全部走 `ThemeTokens`（GPUI）或 CSS 变量（HTML），没有裸值。
- [ ] 窗口 960×640 下不裁切主操作，不出现横向滚动。
- [ ] 深浅两套主题都用同一批 token 名称验证过。
- [ ] 截图在真实窗口里取，不只看设计稿。
