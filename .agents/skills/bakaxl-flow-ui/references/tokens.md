# Token 表

四套主题共用同一组 token 名称，只换取值。**组件与预览只能引用 token，不得出现裸色值。**

## 语义

- `accent`：整屏唯一强调色，只给主操作（启动 / 继续）。一屏出现两处即为缺陷。
- `block`：反色区块（公告块、当前选中的磁贴、头像）。深色主题下会翻成浅色。
- `line`：结构线；`line_soft`：区块内部细分隔线。
- `muted` / `faint`：次级文字 / 极弱标注（时间、序号）。
- OEM 覆盖只允许 `accent` 与 `accent_text`，其余 token 由主题决定。

## 字体

```
--font: system-ui, -apple-system, "Segoe UI", "Segoe UI Variable Text",
        "PingFang SC", "Microsoft YaHei UI", "Noto Sans CJK SC", sans-serif;
--mono: ui-monospace, "Consolas", "Cascadia Mono", "SF Mono", "Menlo", monospace;
```

- 只用系统自带字体，不打包、不分发字体文件。
- 等宽只用于序号（`01`）、日期（`11-08`）、时长（`2H`）、键位提示。
- 中英文都不允许溢出：英文按中文长度的 1.4 倍预留。

## 图标

Lucide 线性，描边 1.5–1.7，基准 20–24；磁贴内 22–24；动作按钮前 15。

## 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 主题切换 | 200ms | `cubic-bezier(0.22,1,0.36,1)` |
| 悬停 | 120–140ms | ease-out |
| 步骤切换 | 200ms | 淡出 90ms → 淡入 200ms + 上移 8px |
| 动作带按钮 | 无动画 | 只用明度变化 |

超过 240ms 的页面转场视为过度设计。
