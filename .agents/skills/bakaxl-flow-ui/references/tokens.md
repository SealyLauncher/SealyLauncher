# Token 表

数值来自 2026-11-08 对 BakaXL 3.5.1 实机截图的取样（`design/preview/bakaxl-oobe-*.png`），
按 SealyLauncher 的窗口尺寸做了等比收敛。**代码与预览共用这一张表，禁止另写裸值。**

## 颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| `shell` | `#1E73D8` | 标题栏、选中态、链接 |
| `shell_deep` | `#1668C9` | 动作带、次级外壳块 |
| `canvas` | `#7FA8D6` | OOBE 内容区底色 |
| `canvas_dark` | `#1A1D24` | 主界面内容区（非 OOBE） |
| `surface` | `#FFFFFF` | 卡片、下拉框、账户卡底 |
| `surface_muted` | `#E8EEF6` | 卡片内次级块 |
| `line` | `rgba(255,255,255,0.28)` | 深底发丝线 |
| `line_dark` | `rgba(0,0,0,0.10)` | 浅底发丝线 |
| `text` | `#FFFFFF` | 深底主文字 |
| `text_muted` | `rgba(255,255,255,0.72)` | 深底次文字 |
| `text_on_light` | `#0B1220` | 浅底主文字 |
| `text_on_light_muted` | `#5A6572` | 浅底次文字 |
| `go` | `#5BC236` | 继续 / 开始 |
| `go_hover` | `#6BD647` | 继续悬停 |
| `back` | `#F7B233` | 返回 |
| `back_hover` | `#FFC24D` | 返回悬停 |
| `danger` | `#D64545` | 删除 / 停止 |
| `watermark` | `#FFFFFF` @ 10% | 品牌线稿 |

OEM 覆盖只允许改 `go` / `back` / `shell` 三支，语义不变。

## 图标

Lucide 线性，描边 1.6–1.8，基准 20；标题栏 16；动作按钮前图标 20。

## 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 步骤切换 | 200ms | `cubic-bezier(0.22,1,0.36,1)`（淡出 90ms → 淡入 200ms + 上移 8px） |
| 悬停 | 120ms | ease-out |
| 按下 | 80ms | 缩放 0.995 或无 |
| 动作带按钮 | 无动画 | 只用明度变化 |

超过 240ms 的页面转场视为过度设计。
