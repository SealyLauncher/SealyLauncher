# BakaXL 式桌面流程界面

本 skill 是 SealyLauncher 的**唯一界面风格基线**，来自 2026-11-08 对 BakaXL 3.5.1 的实机调研。
任何界面（GPUI 代码、HTML 预览、文档插图）都必须先满足这里的规则，再谈局部设计。

参考实拍：`design/preview/bakaxl-oobe-*.png`（欢迎页、语言页、主屏幕显示模式页）。

## 什么时候读

- 新增或重写任何页面、对话框、空状态、OOBE 步骤；
- 调整配色、圆角、间距、字号；
- 做 HTML 视觉预览或设计稿；
- 评审别人的界面（用 `references/checklist.md`）。

## 三条硬规则

1. **一屏一个决定。** 每屏只有一个主操作；两个并列主按钮视为缺陷。
2. **三区固定。** `AppBar` 36px / 内容 / `ActionBar` 64px。有主操作的页面动作带常驻，永远在底部同一位置。
3. **颜色即功能。** 绿=继续或开始，琥珀=返回，蓝=外壳，红=危险。颜色不允许被当作装饰。

违反以上任意一条，不需要再讨论其它细节。

## 视觉基调

- **平面**：大色块 + 1px 发丝线。禁用渐变、玻璃拟态、霓虹光晕、多层投影。
- **水印代替插图**：品牌线稿以 8–12% 不透明度铺满背景，不引入位图素材。
- **面包屑当标题**：`父级 \ 当前步`，不再叠加小标题或副标题。
- **展示优于描述**：选项用预览缩略图表达，不用两段文字解释。
- **加摩擦**：不可逆或授权类步骤用拖动/长按确认，不用复选框。
- **文案**：一句话，第二人称，“您”；不用“请注意”“成功”这类仪式用语。

## 组件与尺寸

| 组件 | 规格 |
| --- | --- |
| 窗口 | 默认 1120×700，最小 960×640，圆角 8 |
| AppBar | 高 36，外壳色；左品牌标 24 + 标题 13/600；右工具项 12.5 |
| Breadcrumb | 步骤名 24/600 白，`\` 与副名 24/400 白 72% |
| ActionBar | 高 64，深外壳色；左侧一句话 15/400，右侧按钮占满带高 |
| ActionButton | 高 64（整带），宽 160–220，字号 24/600，无圆角（贴边） |
| OptionCard | 预览图 16:9、圆角 6、1px 白 40% 描边、单选 12px、标题 15/600、说明 12 |
| 卡片 | 圆角 6，1px 发丝线，内边距 16 |
| 按钮（页内） | 高 36，圆角 4，主按钮绿色填充 |
| 正文 | 13/400；元数据 11/500 |

完整 token 表见 `references/tokens.md`。

## 落地方式

- **GPUI**：`sealy-ui` 里先落 `AppBar` / `ActionBar` / `Breadcrumb` / `Watermark` / `OptionCard` 五个基础件，
  颜色圆角从 `ThemeTokens` 取，不写裸值；不引入 `gpui-component` 默认外观。
- **HTML 预览**：单文件，1280×800，纯 CSS/SVG，无外部资源；预览必须与 GPUI 同一套 token 数值。
