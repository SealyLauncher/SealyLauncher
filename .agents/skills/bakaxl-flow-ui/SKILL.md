# BakaXL 式桌面流程界面

本 skill 是 SealyLauncher 的**唯一界面风格基线**，来自 2026-11-08 对 BakaXL 3.5.1 的实机调研。
任何界面（GPUI 代码、HTML 预览、文档插图）都必须先满足这里的规则，再谈局部设计。

参考实拍：`design/preview/bakaxl-oobe-*.png`（欢迎页、语言页、主屏幕显示模式页）。

## 什么时候读

- 新增或重写任何页面、对话框、空状态、OOBE 步骤；
- 调整配色、圆角、间距、字号；
- 做 HTML 视觉预览或设计稿；
- 评审别人的界面（用 `references/checklist.md`）。

## 三条硬规则

1. **一屏一个决定。** 每屏只有一个主操作；两个并列主按钮视为缺陷。
2. **三区固定。** `AppBar` 40px / 内容 / `ActionBar` 72px。有主操作的页面动作带常驻，永远在底部同一位置。
3. **颜色即功能。** 整屏只有一个强调色（`accent`），只用于主操作；其余层级靠分格线、字号、留白。

违反以上任意一条，不需要再讨论其它细节。

## 视觉基调

- **平面**：色块 + 1px 发丝线。禁用渐变、玻璃拟态、霓虹光晕、多层投影。
- **纸白优先**：默认 `paper` 主题（暖白底 + 纯黑强调），深色是同一套 token 的另一组取值。
- **系统字体**：只用系统 UI 栈与系统等宽栈，不打包、不分发字体文件。
- **面包屑当标题**：`父级 \ 当前步`，不再叠加小标题或副标题。
- **禁止装饰性小字**：网络延迟、Java 版本、上次游玩时间、构建号不进界面框架；
  需要时用图标、状态点表达，或收进设置/日志页。
- **展示优于描述**：选项用预览缩略图表达，不用两段文字解释。
- **加摩擦**：不可逆或授权类步骤用拖动/长按确认，不用复选框。
- **文案**：一句话，第二人称，“您”；不用“请注意”“成功”这类仪式用语。

## 组件与尺寸

| 组件 | 规格 |
| --- | --- |
| 窗口 | 默认 1120×700，最小 960×640，圆角 6 |
| AppBar | 高 40，`surface` 色；左品牌标 10.5 等宽；右窗口控件 42×40 |
| Breadcrumb | 步骤名 30/620，`\` 与副名 26/400 `muted` |
| ActionBar | 高 72，`surface` 色；左侧一句话 13/400 `muted`，右侧按钮占满带高 |
| ActionButton | 高 72（整带），宽 ≥178，字号 22/600，无圆角（贴边） |
| Tile | 圆角 2，1px `line`；小 84×84，中 178×178，宽 366×178，大 272×366 |
| 卡片 | 圆角 2，1px 发丝线，内边距 14–18 |
| 按钮（页内） | 高 58，圆角 2，`accent` 填充 |
| 正文 | 13/400；等宽标注 9.5–10 |

完整 token 表与四套主题见 `references/tokens.md`。

## 落地方式

- **GPUI**：`sealy-ui` 里先落 `AppBar` / `ActionBar` / `Breadcrumb` / `Watermark` / `OptionCard` 五个基础件，
  颜色圆角从 `ThemeTokens` 取，不写裸值；不引入 `gpui-component` 默认外观。
- **HTML 预览**：单文件，1280×800，纯 CSS/SVG，无外部资源；预览必须与 GPUI 同一套 token 数值。
